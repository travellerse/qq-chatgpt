# qq-chatgpt
使用openai官方api进行chatgpt调用的qq机器人，配合go-cqhttp使用

> [!WARNING]
> 该项目已不再维护，并已存档。我已决定停止该项目的开发，专注于其他项目。
> 
> This project is no longer maintained and has been archived. I have decided to discontinue its development to focus on other projects.

# 使用方法
使用pip install -r requirment.txt安装依赖，运行app.py

打开go-cqhttp，并将上报端口调至默认端口9000


# 注意
本程序默认使用的端口为9000，可在配置文件config.yaml中修改

在配置文件中设置代理，默认为 http://127.0.0.1:7890
